# Pokédex CLI

A command-line Pokédex built with TypeScript and the [PokéAPI](https://pokeapi.co/) as part of the [Boot.dev](https://www.boot.dev/) Build a Pokédex course.

## Learning Goals

- Make HTTP requests in TypeScript
- Build an interactive command-line REPL
- Work with local TypeScript development tools
- Use caching to improve performance
